## 4 règles Romayroh (1 par section)

### Règle 1 — Long-form 10-20 min strict (2 min)
- 94% des AI-cited videos = long-form
- Shorts = 5% seulement
- Le sweet spot = 10-20 min (1/3 des citations)
- Métaphore : « Les agents IA c'est comme des étudiants en philo — ils veulent du contenu qui développe, pas des TikTok flashy »

### Règle 2 — Chapters dans description (2 min)
- 78% des vidéos avec chapters = citées plusieurs fois
- L'AI traite chaque chapter comme un mini-article indépendant
- Démontre : 5 chapters = 5 portes d'entrée différentes
- Show comment ajouter (timestamps `00:00` `01:30` `04:00` etc.)

### Règle 3 — Description 500+ mots avec entités nommées (2 min)
- L'AI parse les entités : marques, lieux, concepts, personnes
- Démontre : description courte vs longue avec brands + lieux + concepts nommés
- Exemple Pat : mentionner "Anthropic Claude", "Modal", "ElevenLabs", "Drummondville", "Lac-Saint-Jean", "ffmpeg", "NousResearch Hermès Agent" = chaque entité = potentielle citation

### Règle 4 — Transcript manuel uploadé (2 min)
- YouTube auto-caption = mauvais (orphelins "L'", "C'", noms propres ratés)
- Workflow : YT Studio → Subtitles → Autosync → coller transcript propre
- Pourquoi c'est critique : l'AI lit le transcript pour citer le passage exact

### Bonus — llm.txt + Knowledge Graph Overlay (1.5 min)
- Si t'as un site WordPress : plugin Yoast → enable llm.txt = +70% classement IA
- Knowledge Graph Overlay = Schema.org/VideoObject dans description = AI indexe à la seconde
