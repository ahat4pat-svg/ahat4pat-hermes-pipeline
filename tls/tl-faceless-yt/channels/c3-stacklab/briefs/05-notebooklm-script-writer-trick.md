## Plan 4 étapes

### Étape 1 — Trouver le sujet trending en 2 minutes (1.5 min)
- Ouvre YouTube → search ton mot-clé large (ex : "psychologie")
- Filtres : "Popularity" + "This month"
- Note le top 1 résultat (= ton sub-niche validé)
- Re-search avec le sub-niche exact
- Grab les 5 top URLs

### Étape 2 — Sourcer 10 references dans NotebookLM (1.5 min)
- Ouvre NotebookLM (gratuit avec Google account)
- New notebook
- Paste les 5 URLs YouTube
- Google search le même sujet → grab 5 top articles → paste URLs
- 10 sources total = ta base de vérité

### Étape 3 — LE TRICK : custom config prompt (2.5 min)
- Settings icon → Chat section → "Custom"
- Paste ce prompt verbatim (visible à l'écran, screenshot opportunity) :
```
You are a world-class YouTube script writer. Generate scripts that:
1. Open with a 5-7 sec hook using an information gap
2. Pattern interrupt every 60-90 seconds
3. Use conversational French-Canadian tone
4. Include specific metaphors from everyday Quebec life (SAAQ, dépanneur, hiver, etc.)
5. End with a strong CTA driving to description
6. Cite the 10 sources naturally without breaking flow
7. Match the proven hook structure of the source videos
```
- Save

### Étape 4 — Générer le script (1.5 min)
- Chat tab → simple prompt :
```
Write a 1000-word YouTube script about [TOPIC].
```
- 60 sec → output complet sourcé sur les 10 references
- Démontre live : montre le résultat
- Pat lit les premières lignes du script généré — l'audience entend la qualité

### Étape 5 — De script à vidéo en 1h (1 min)
- Copy script dans ChatGPT avec ce prompt : "Read this script and assign a visual type to each line: Host on Camera, Text Overlay, Stock Footage, AI Generated"
- Output = production table scene-par-scene
- Tu sais exactement quoi produire pour chaque ligne
- Stock footage via Pexels gratuit + AI generated via Google Flow Nano Banana 2
